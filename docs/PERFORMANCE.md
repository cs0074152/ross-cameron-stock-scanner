# 性能优化完成（2026-10-08）

桌面入口已切换为缓存的生产页面，仍使用桌面“美股与A股扫描器”图标。

本机实测：

| 项目 | 结果 |
| --- | --- |
| 已缓存构建后，进程启动至服务就绪 | 852 / 858 / 867 毫秒，中位数 858 毫秒 |
| 重复启动并识别现有实例 | 259 / 268 / 276 毫秒，中位数 268 毫秒 |
| 核心首屏资源请求 | 3 次（HTML、JS、CSS，不含图标和外部行情） |
| 核心首屏压缩传输量 | 62,948 字节，约 63 KB |
| 同机开发模式基线 | 12 个模块/样式请求，约 3.61 MB 开发输出 |

这里测量的是本机服务就绪与 HTTP 资源传输，不是浏览器首屏绘制或图表完整加载时间。首次构建或源文件改变时需要重新构建。

完成的优化：

- 桌面启动不再启动开发编译服务；源文件、配置、环境及锁文件的内容指纹相同且产物完整时直接复用构建。
- 前后端同时启动；实际 API/WS 地址启动时注入页面，换端口不需要重新编译。
- 页面服务器预读资源、压缩传输，带哈希的资源长期缓存，HTML与启动身份不缓存。
- 策略页面按需加载，首屏 JS 从 200.44 KB 降至 176.12 KB；减少整表重复渲染、排序和时间格式器创建。
- TradingView 初始化推迟到页面绘制后，切换股票/市场/主题时可取消旧任务。
- Cheerio 在需要解析盘前/盘后 HTML 时才加载；后端加载基线约 605–733 毫秒，优化后约 286 毫秒。
- 美股成功榜单逐类别先发布；A股完整三榜返回后先发布，再等待独立持仓报价。策略、持仓保存和版本递增仍只在完整阶段处理。

验证：后端138项、前端20项，共158项测试全部通过；生产构建通过。持仓持久化、重连、幂等平仓、双市场隔离和失败缓存回归保留。独立校验旧后端，避免前端失效后启动第二个持仓写进程。本页记录优化时的本机测量；后续发布不改变以上测量口径。
