# 美股 / A 股股票扫描器

本机运行的双市场行情观察工具。每 15 秒尝试刷新行情，提供榜单、数值筛选、TradingView 图表、快照买点观察、模拟持仓监控和盈亏记账。不会连接券商或执行交易。

## 安装与启动

需要 **Node.js >=22.12.0**，建议使用 Node 24，以及 npm。

- Windows：双击项目根目录的 `start.bat`；桌面图标可通过 `create-desktop-shortcut.bat` 创建。
- Git Bash / Linux / macOS：从任意目录执行 `bash /项目路径/start.sh`。
- 启动器自动按锁文件安装缺失依赖，检查前后端是否真正就绪。重复点击会打开已验证的本项目实例；端口被旧服务占用时自动选择空闲端口，并同步前后端连接。按 Ctrl+C 只停止本次启动的服务。
- 桌面入口使用打包后的页面，首次或源文件变更时自动构建；以后直接复用经过完整性校验的缓存。页面资源压缩传输并按内容缓存，API 地址随启动注入，切换端口无需重建。开发时仍可使用 `npm run dev`。
- 默认页面地址：`http://localhost:5173`，默认后端：`http://127.0.0.1:3001`。实际地址显示在启动窗口，并记录在 `.runtime/launcher.json`；启动日志在 `.runtime/launch.log`。

手动启动时分别打开两个终端：

```text
cd backend
npm ci
npm start
```

```text
cd frontend
npm ci
npm run dev -- --port 5173 --strictPort
```

后端支持 `backend/.env` 中的 `HOST`、`PORT`、`ALLOWED_ORIGIN`、`STATE_FILE`。HOST 仅允许本机回环地址。启动器会同步前端连接地址；手动使用自定义端口时设置前端 `VITE_API_BASE`，WebSocket 默认由该地址派生，也可设置 `VITE_WS_BASE`。

## 行情与扫描范围

| 市场 / 时段 | 来源 | 范围与时效 |
| --- | --- | --- |
| 美股盘中及闭市参考 | Yahoo Finance | 三类预设榜单各最多 200 只，数据源可能返回更少；不是全市场扫描 |
| 美股盘前 | StockAnalysis 盘前页面 | 公开页面可解析的涨跌及活跃榜单；没有精确报价时间的行仅作参考 |
| 美股盘后 | StockAnalysis 盘后页面 | 真正盘后涨跌榜；目前无可靠盘后活跃榜，成交活跃类别为空 |
| A 股 | 东方财富沪深京行情 | 涨幅、跌幅、成交量各最多 200 只，去重后筛选；不是全市场扫描 |
| 持仓 / 选中股票 | Yahoo 独立 quote / 东方财富 ulist.np | 每轮独立获取，不依赖股票是否仍在榜单 |

页面分别展示抓取成功时间与源报价时间。报价未知或活动时段超过 3 分钟时，持仓显示“行情过期”，停止新的止损 / 止盈判断；不推进旧报价时间，不用旧报价计算活动时段模拟平仓。

榜单失败会保留最后有效数据并显示错误。每类别状态保留成功时间与所属时段；合并按源报价新旧处理。公开行情源可能延迟、限流或改变页面结构，连接正常并不意味着价格已经更新。StockAnalysis 无法提供的流通盘、量比、真实开盘跳空或成交量显示“—”，不再编造估值。

A 股价格为人民币，成交量按股，流通股数由流通市值 / 价格估算；红涨绿跌。图表使用 `SSE:代码` / `SZSE:代码`，北交所提供东方财富备用链接。选中股票退出榜单后继续保留图表并独立订阅报价。

## 筛选与策略

- 支持价格上下限、最低涨幅、最低量比及最大流通股数自定义筛选；缺失指标不会被当作真实零值。筛选只作用于当前样本。
- “价格 / 涨幅初筛”：美股价格 $1–$20、涨跌幅绝对值 >=10%，并非五项全部满足。
- 严格五项数值筛选：价格 $1–$20、流通盘 <1000 万、跳空 >=4%、量比 >=2、涨跌幅绝对值 >=10%；新闻催化需人工核实。
- 文档选股：价格 $2–$20、涨幅 >10%、量比 >=5、流通盘 <2000 万；严格版为 $5–$10、涨幅 >30%、量比 >=5、流通盘 <1000 万。
- 接近日高动量：涨幅 >=5%，现价距当日高点 <=0.2%。它不是逐笔创新高检测。
- 跳空：真实开盘价相对昨收的绝对变化 >=4%；零跳空不会回退成盘中涨幅。
- 买点雷达用源时间戳报价形成 15 分钟样本，按交易日隔离，区间价与累计日高分开。是行情快照，不是真实 K 线；美股非盘中仅观察。
- A 股有独立观察与持仓页面。候选数值条件为 5–100 元、涨幅 >=3%、量比 >=1.5，排除已知 ST、新股和接近常规涨停的股票。上市日期 / 实际涨停价未提供时需人工核实。主板、创业板、科创板及北交所分别标注；常规涨跌幅比例不能代替个股实际涨停价。
- A 股观察信号不能直接套用美股日内策略。T+1 根据最新买入日期及已登记交易日历判断；增持会重新限制整笔模拟持仓。界面按 100 股整数倍登记，实际科创板等委托数量规则需核实。
- 行情无法判断的大卖单和主笔成交保持“人工盯盘”标注。

## 持仓与盈亏

后端以原子 JSON 写入保存持仓、入场时间、峰值、源报价和幂等平仓收据，默认路径为 `backend/data/positions.json`，被 Git 忽略。可用 `STATE_FILE` 指定其他本机路径。存储损坏或保存失败会明确报错，不能静默覆盖。

后端数据是权威状态。前端每次连接先对账，首次仅在该市场从未有持久状态时迁移旧浏览器镜像；持久空仓不会被旧镜像复活。浏览器镜像和盈亏记录按 US / CN 分开。仅请求确认成功后更新页面，平仓使用可重试的唯一操作 ID，收据重放不会重复计账。前后端重启不会清空持仓。

盈亏按美东 / 北京日期归档并保留历史，页面持续运行时自动切换当日记录。断线丢失的成功平仓响应可以从服务器收据恢复。平仓是模拟记账，使用最近有效源报价，包含未扣手续费的价差盈亏。

## 交易日历

`backend/market-calendars.json` 独立维护日历并附官方来源：当前登记美股 2026–2028 年休市 / 提前收盘、A 股 2026 年休市。美股时钟处理夏令时；A 股处理两次集合竞价和午休。未知年份返回 `session=unknown`，不把工作日推算标成已核实交易日，暂停 A 股自动平仓放行。后续年度应在交易所公布后更新 JSON 并跑日历测试。

## 文件与接口

后端分为 `server.js`（协调 / API）、`safe-fetch.js`、`market-us.js`、`market-cn.js`、`market-calendar.js`、`scanner-filters.js`、`strategy.js`、`positions.js`。前端状态与日期工具在 `frontend/src/scanner-state.js`；启动逻辑在 `scripts/launch.cjs`。

所有接口默认 `market=US`，可指定 `?market=CN`；POST 也可在 JSON body 指定市场。

```text
GET    /api/health
GET    /api/scanner/:category
GET    /api/positions
GET    /api/trades
POST   /api/positions
POST   /api/positions/sync
POST   /api/watch
DELETE /api/positions/:symbol?market=US&operationId=唯一操作ID
WS     ws://localhost:3001/?market=US
```

持仓响应带 `positionsDurable`、`migrationNeeded`、`instanceId` 和 `positionsRevision`，用于迁移、重连和拒绝旧快照。仅本机使用；保留 Origin / 类别白名单、1 MiB WebSocket 消息上限和出站域名白名单。新增源须通过 `safeFetch()`，不得将服务或 Vite 暴露到公网。
